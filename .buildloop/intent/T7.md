# T7: felt as a native iOS app

**Asked (Zac, 2026-11-14):** "add an ios app to this one! A complete overhaul and pixel and physics perfect
rebuild onto swift onto ios! go for it!" Approach chosen when asked: **phased native port** (not a WKWebView
shell): a real Swift port, the sim first with a golden-trace harness proving Swift == JS, one table playable,
the rest over later sessions.

**Constraints:** physics perfect means the same doubles as index.html's sim; the web build stays the source of
truth and is not changed by the port; offline; no third-party dependencies.

**Phases:** T7.1 physics core + harness + playable practice table (this session). Later: rules (sim 1e) and
the CPU (1f) against judge/cpuSearch goldens; bumper pool (1g); the renderer to pixel parity (section 4,
measured against render-check's images); HUD, setup, settings, career, modes, 3D, intro.

**Open:** whether the web build should adopt fdlibm too (it would make the page deterministic across V8
arm64, V8 x86 and Safari, but moves every stored solution: tricks, drills, tutorials, hero shots re-solved).
